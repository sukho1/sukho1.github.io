# 马庄心理学 · sukho1.github.io

发布在 <https://sukho1.github.io/> 的静态站点，内容是 [assistant-agent](https://github.com/sukho1/assistant-agent) 项目 `knowledge/` 目录下的全部知识库文章（马克思+庄子+心理学体系）。

- 本仓库内容由脚本自动生成，**不要手动改页面**：改知识文章请去 assistant-agent 仓库的 `knowledge/`。
- 生成器：`assistant-agent/program/scripts/build_knowledge_site.py`（需要 pandoc）。
- 重新生成：`python program/scripts/build_knowledge_site.py`，输出即本仓库目录，然后 push 即可更新网站。
- 站点特性：按五个系列分组（庄子/链接/业障/马克思/自体心理学），首页客户端全文搜索（search-data.js 内嵌 225 篇全文）。
